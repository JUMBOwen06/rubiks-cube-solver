# Rubik's Cube Solver
A 3x3 Rubik's Cube solver written in C, with a 3D OpenGL visualization.

## Status
Early development.
- Cube state representation and move logic
    - U and U'
    - D and D'
    - R and R'
    - L and L'
- Clean file strucutre

    make run
