# Rubik's Cube Solver
A 3x3 Rubik's Cube solver written in C, with a 3D OpenGL visualization.

## Status
Early development.
- Cube state representation and move logic are done
    - U and U'
    - D and D'
    - R and R'
    - L and L'
    - F and F'
    - B and B'
- Clean file strucutre so far

## Build
    make
    make run
